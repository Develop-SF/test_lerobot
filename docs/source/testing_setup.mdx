# Testing Branch Documentation Setup

This guide explains how to build and preview the interactive documentation for the testing branch.

## Prerequisites

### Install Documentation Dependencies

```bash
cd /home/shinfang-ovx/workspaces/test_lerobot

# Install doc-builder and dependencies
pip install -e ".[docs]"

# Install watchdog for live preview
pip install watchdog
```

### Install Node.js

If you don't have Node.js installed, you can install it via:

**Ubuntu/Debian:**
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs
```

**Or using conda:**
```bash
conda install -c conda-forge nodejs
```

## Building the Documentation

### Build Static Documentation

To build the documentation as static HTML:

```bash
cd /home/shinfang-ovx/workspaces/test_lerobot

# Build documentation
doc-builder build lerobot docs/source/ --build_dir ~/tmp/lerobot-docs

# The HTML files will be in ~/tmp/lerobot-docs
```

### Preview Documentation Locally

To preview the documentation with live reload:

```bash
cd /home/shinfang-ovx/workspaces/test_lerobot

# Start preview server
doc-builder preview lerobot docs/source/

# Open browser to http://localhost:3000
```

The preview server will:
- Build the documentation
- Start a local web server at http://localhost:3000
- Watch for file changes and auto-reload
- Show your new testing branch pages in the navigation

<Tip>

**Note:** When you add completely new files (like we did with `testing_branch.mdx` and `testing_quickref.mdx`), you need to:
1. Update `_toctree.yml` (already done ✅)
2. Restart the preview server (Ctrl-C to stop, then run preview command again)

</Tip>

## Customizing the Documentation

### Adding More Pages

To add more documentation pages:

1. **Create MDX file** in `docs/source/`:
   ```bash
   touch docs/source/my_new_page.mdx
   ```

2. **Add to `_toctree.yml`**:
   ```yaml
   - sections:
     - local: testing_branch
       title: Testing Branch Guide
     - local: testing_quickref
       title: Quick Reference
     - local: my_new_page
       title: My New Page
     title: "Testing Branch"
   ```

3. **Restart preview server** to see changes

### Using MDX Features

The documentation uses MDX format which supports:

#### Code Blocks

```python
# Python code example
from lerobot.common.datasets import LeRobotDataset

dataset = LeRobotDataset("my_dataset")
```

#### Tips and Warnings

```mdx
<Tip>
Helpful tip here!
</Tip>

<Tip warning={true}>
Important warning!
</Tip>
```

#### Tables

```mdx
| Column 1 | Column 2 |
|----------|----------|
| Value 1  | Value 2  |
```

#### Links

```mdx
[Link to another page](testing_quickref)
[External link](https://huggingface.co/lerobot)
```

## Deployment

### Deploy to GitHub Pages

Once you're happy with the documentation:

1. **Commit changes:**
   ```bash
   git add docs/source/testing_branch.mdx
   git add docs/source/testing_quickref.mdx
   git add docs/source/_toctree.yml
   git commit -m "Add testing branch documentation"
   git push origin testing
   ```

2. **Open Pull Request** to merge into main

3. **Automatic deployment:** The documentation will be automatically built and deployed when changes are merged

### Deploy to Hugging Face Spaces

You can also deploy the documentation as a Hugging Face Space:

1. **Create a Space** at https://huggingface.co/new-space
2. **Select "Gradio" or "Streamlit"** as the SDK
3. **Push documentation** to the Space
4. **Configure** to serve the built HTML files

## Troubleshooting

### Issue: doc-builder not found

**Solution:**
```bash
pip install hf-doc-builder
```

### Issue: Node.js not found

**Solution:**
```bash
# Ubuntu/Debian
sudo apt-get install nodejs npm

# Or with conda
conda install -c conda-forge nodejs
```

### Issue: Preview not updating

**Solution:**
1. Stop the preview server (Ctrl-C)
2. Clear any cache: `rm -rf ~/.cache/doc-builder`
3. Restart: `doc-builder preview lerobot docs/source/`

### Issue: Port 3000 already in use

**Solution:**
```bash
# Find and kill process using port 3000
lsof -ti:3000 | xargs kill -9

# Or use a different port
doc-builder preview lerobot docs/source/ --port 3001
```
