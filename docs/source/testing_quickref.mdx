# Testing Branch Quick Reference

Quick command reference for the testing branch workflow.

## Pipeline Overview

```
ROS Bag → Dataset → Training → ONNX → Inference → Robot
```

## Setup and Tips

- **Environment Setup**: Follow LeRobot's README to set up the conda environment and install LeRobot locally.
- **Suppress Verbose Logs**: Verbose Svt[info] logs can be distracting. Set `export SVT_LOG=1` in the terminal to suppress them except in case of errors.
- **Parallel Conversion**: Use `run_parallel_conversion.sh` to speed up the conversion process via parallel processing of multiple episodes.
- **Script Configuration**: For conversion scripts, typically only need to edit `BASE_DIR`, `OUTPUT_DIR`, episode count's bag root folder name, `--dataset-name`, and `--task` parameters.

### Standard Conversion

```bash
cd dev/data_processing/conversion

python rosbag_to_lerobot_rosbag2.py \
    /path/to/rosbags \
    --output-dir /path/to/dataset \
    --dataset-name "my_dataset" \
    --fps 20 \
    --input-mode vision_pos \
    --output-mode pos_vel
```

### Using Shell Script

```bash
# Edit paths in the script first
bash run_approach_new_converter.sh
```

## 2️⃣ Train Model

### Absolute Actions

```bash
python lerobot/scripts/train.py \
    --config-path config.json \
    --output-dir /path/to/output
```

### Relative Actions (Recommended)

```bash
python lerobot/scripts/train_with_relative_actions.py \
    --config_path config.json \
    --output_dir /path/to/output \
    --use_relative_actions \
    --arm_dim 6
```

### Compute Statistics (Optional)

```bash
python lerobot/scripts/compute_relative_action_stats.py \
    --dataset-path /path/to/dataset \
    --arm-dim 6 \
    --output-path stats.json
```

## 3️⃣ Convert to ONNX

### Absolute Actions

```bash
cd dev/inference/testing_abs

python convert_to_onnx.py \
    --checkpoint /path/to/checkpoint \
    --output-dir ./onnx_models
```

### Relative Actions

```bash
cd dev/inference/testing_rel

python convert_to_onnx_rel.py \
    --checkpoint /path/to/checkpoint \
    --output-dir ./onnx_models \
    --use-relative-actions \
    --arm-dim 6
```

## 4️⃣ Run Inference

### Test with Rosbag

```bash
python test_rosbag.py \
    --checkpoint /path/to/checkpoint \
    --rosbag /path/to/test.bag
```

### Evaluate Predictions

```bash
python evaluate_predictions_onnx.py \
    --checkpoint /path/to/checkpoint \
    --rosbag /path/to/rosbag \
    --onnx-dir ./onnx_models \
    --plot
```

### Deploy on Robot

```bash
python inference_node_onnx.py \
    --checkpoint /path/to/checkpoint \
    --onnx-dir ./onnx_models \
    --device cuda \
    --frequency 20.0
```

## Input/Output Modes

| Mode | Description | Observation Dim | Action Dim |
|------|-------------|----------------|------------|
| `vision_only` | Images only | Images | 6 or 12 |
| `vision_pos` | Images + positions | Images + 6 | 6 or 12 |
| `vision_pos_vel` | Images + pos + vel | Images + 12 | 12 |
| `pos_only` | Position outputs | - | 6 |
| `pos_vel` | Position + velocity | - | 12 |

## Troubleshooting

| Issue | Solution |
|-------|----------|
| CUDA OOM | Use `--device cpu` or `--frequency 10.0` |
| Image size mismatch | Check crop/resize parameters |
| Robot not moving | Verify topics and controller |
| Slow inference | Use ONNX, reduce frequency |

## Performance Comparison

| Backend | Speed | Use Case |
|---------|-------|----------|
| PyTorch CPU | 1x | Testing |
| PyTorch CUDA | 2-3x | Development |
| ONNX CPU | 1.5-2x | Production (no GPU) |
| ONNX CUDA | 3-5x | Production |
| ONNX+TensorRT | 5-10x | Real-time ⭐ |

## Complete Example

```bash
# 1. Convert
python rosbag_to_lerobot_rosbag2.py /data/bags \
    --output-dir /data/dataset --dataset-name exp1 --fps 20

# 2. Train
python train_with_relative_actions.py \
    --config_path config.json --output_dir /data/model \
    --use_relative_actions --arm_dim 6

# 3. Convert to ONNX
python convert_to_onnx_rel.py \
    --checkpoint /data/model/checkpoints/best \
    --output-dir /data/model/onnx \
    --use-relative-actions --arm-dim 6

# 4. Test
python evaluate_predictions_onnx_rel.py \
    --checkpoint /data/model/checkpoints/best \
    --rosbag /data/test.bag \
    --onnx-dir /data/model/onnx --plot

# 5. Deploy
python inference_node_onnx_rel.py \
    --checkpoint /data/model/checkpoints/best \
    --onnx-dir /data/model/onnx --frequency 20.0
```
